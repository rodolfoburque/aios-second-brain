# Conduct

Corrections from the vault owner, one line each. This file is loaded whole into every session (`@AIOS/conduct.md` in `CLAUDE.md`), so what is written here always applies.

How to write one: a single sentence that says what to do, with the date of the correction in parentheses, in the language the owner uses. No backstory, no long example. A correction that replaces an older one rewrites the old line instead of adding a new one. A mistake made by one specific skill does not go here: it goes into that skill.
