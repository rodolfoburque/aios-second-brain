# Resources: rules for this folder

Reusable personal library. Prompts, frameworks, references, templates.

## What goes here
- Reusable prompts (beyond the ones already in `prompts/`)
- Reference frameworks and methodologies
- Swipe files: examples of content that worked
- Document templates
- Files from finished projects

## Suggested organization
```
04 Resources/
├── prompts/       ← additional prompts beyond the starter kit
├── frameworks/    ← reference methodologies
├── swipe/         ← examples and inspiration
├── templates/     ← document templates
└── archive/       ← finished projects and content
```

## Rules
- When the user shares a reusable prompt, framework or template: save it here with a descriptive name
- When the user says "save this for later": route it here
- Do not create empty subfolders: create the folder only when there is content for it
