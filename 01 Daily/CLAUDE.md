# Daily: rules for this folder

Daily notes. One per day, format `YYYY-MM-DD.md`.

## When to create
- At the start of each work session, if today's note does not exist

## Default structure
```markdown
---
type: daily-note
date: YYYY-MM-DD
status: active
tags: [daily]
---

## Focus of the day
- {{what needs to get done today}}

## Session
- **Worked on:** {{project or task}}
- **Result:** {{what was done}}
- **Next step:** {{what comes next}}

## Notes
{{any quick capture, idea, decision}}
```

## Rules
- Never edit a note from a previous day: create a new one
- When you capture something important (decision, insight, new project), route it to the right folder and leave only a wikilink here
- If the user says "note this" or "save this here", save it in today's note
